# Attribution and source provenance

This repository contains an unofficial HTC HD2 adaptation of Sailfish OS. Sailfish/Jolla, CyanogenMod, HTC, Qualcomm and upstream authors retain their respective rights. Original notices in reference code and ROM components continue to apply; no blanket relicensing of third-party firmware or code is intended.

`sources.lock.json` records the pinned HD2 base, anzu Sailfish donor, kernel/device sources, reference projects and toolchain. `reference-sources/` contains the upstream code used for compatibility analysis and retains its original licenses. The Release attaches the modified HD2 kernel source, configuration, local diff and compiler references. Proprietary userspace binaries are distributed only in the ROM release archive.
